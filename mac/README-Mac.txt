业码汇 Mac 版

需要 macOS 和 Python 3.11 或更新版本。首次启动需要联网安装 Python 依赖，之后无需 Node.js。
解压 ZIP 到固定目录，双击“启动.command”，浏览器访问 http://127.0.0.1:8000。
双击“停止.command”关闭服务。数据、数据库备份和密钥保存在本目录 data 文件夹；升级前请备份整个 data 文件夹。
发布包默认监听 `0.0.0.0:8000`，因此本机、局域网 IP 和公网 IP 均使用同一个端口访问。首次启动会把包内的 `server.default.json` 自动复制到 `data/server.json`；以后只需替换该配置文件即可改变监听地址和端口，无需修改启动脚本。
公网访问还需要放行主机防火墙、云安全组或路由器端口转发；系统本身提供 HTTP，不包含 HTTPS。
首次设置必须在本机完成。
