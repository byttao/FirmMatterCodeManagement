Windows / Windows Server 部署手册

业码汇
安装与初始化

下载 Windows 发布包，解压到固定目录，运行 Manager.exe 即可安装和启动后台服务。发布包自带 Python 运行环境，正式运行无需另装 Python 或 Node.js。

安装

1

解压完整安装包

将 ZIP 解压到固定位置，例如 C:\FirmMatterCodeManagement。请保留全部文件，不要只复制 EXE。

2

打开管理工具

双击 Manager.exe，接受 Windows 管理员权限提示。管理工具会安装开机自启的系统服务。

3

一键启动

默认监听 0.0.0.0:8000，无需手动修改即可通过本机、局域网 IP 或公网 IP 访问。需要时再调整监听范围和端口，工具会配置入站防火墙并打开本机页面。

首次启用必须在服务器本机完成。通过远程桌面登录服务器后，让管理工具打开 127.0.0.1:端口/setup。安装完成后其他电脑才能按权限登录。

首次启用

  1. 创建管理员账号并设置至少 8 位密码。
  2. 选择首个编号年度，填写事务所名称。
  3. 为各事务所填写业务类型和编号模板。支持 {yyyy}（2026）、{yy}（26）以及 {n} 到 {nnnnnnnnnn} 的序号占位符；模板必须含 {yyyy} 与一个序号占位符，例如 {yyyy}-{nnn}。
  4. 完成后登录，在“用户管理”建立执业人员账号，再在“签字人管理”按账号关联签字人。同名人员以账号区分。

系统不会预置事务所名称、文号、管理员账号或业务数据。

访问地址

监听范围127.0.0.1 只供服务器本机访问；0.0.0.0 允许通过服务器本机、局域网 IP 或公网 IP 访问，发布包默认使用此值。
端口默认 8000。管理工具会为所选端口设置 Windows 入站防火墙规则。
外部 IP 或域名填写服务器 IP 或域名，不含 http:// 和端口。域名须提前配置 DNS；跨公网还需配置云安全组或路由器端口转发。
HTTPS管理工具提供 HTTP 服务，不包含 HTTPS。公网处理业务数据时请放行主机防火墙、云安全组或路由器端口转发；敏感业务建议另行配置 HTTPS 反向代理。

管理工具中的“检测外部地址”从服务器本机发起请求；其他网络的可达性仍需从对应客户端确认。

更新与备份

  • v0.2.0 是新结构测试版本，不读取旧数据库，不提供原地升级或迁移。
  • 下载完整 FirmMatterCodeManagement-win-x64.zip，校验SHA-256后解压到新的固定本地目录。
  • 保留原 data、密钥和配置的可恢复备份，不能覆盖旧安装目录或自动清库。
  • 新版本首次初始化只能从服务本机完成，管理员密码至少12位。
  • 从旧单文件版首次切换时，先停止服务并关闭旧管理工具，备份整个 data，将新版 ZIP 解压覆盖原目录且保留 data，再运行新版 Manager.exe。旧版管理工具无法直接安装新格式 ZIP。
五角色、开票资料版本与快照、15天租约及导出队列尚待后续批次；本版不表示总方案完成验收。

前置环境

发布包无需额外安装 Python、Node.js 或 Rust。两个 EXE 采用文件夹模式打包，分别依赖同级的 Manager-internal 和 BackendServer-internal 目录；请勿单独移动 EXE。启动时无需反复解压运行时。源码维护所需的软件请在开发环境单独安装。

支持 64 位 Windows 10/11 和带桌面体验的 Windows Server。无桌面体验的 Server Core 无法打开管理界面，可使用系统服务命令管理已安装的服务。
