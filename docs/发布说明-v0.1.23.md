# v0.1.23 修复年度占位符校验与授权激活状态

## 主要修改

- 编号模板校验同时支持 `{yyyy}` 四位年度和 `{yy}` 两位年度占位符，编号生成结果保持与模板一致。
- 初始化向导允许在试用配置下直接导入授权文件并完成激活，不再静默忽略授权文件。
- 首次激活时从授权服务器读取并缓存 Ed25519 公钥，验证服务器返回的签名许可证；有效许可证在试用环境也显示为“已授权”。
- 授权心跳支持缓存许可证，服务重启后仍能保持已授权状态。

## 验证

- 后端完整测试套件 24 项通过。
- 前端 TypeScript 检查与 Vite 生产构建通过。
- 使用 `.liscence` 授权文件完成真实授权服务器激活，状态接口返回 `mode: licensed` 和“授权有效”。
- 通过 ego-browser 访问测试环境初始化路由及授权状态接口，确认页面返回已授权状态。
