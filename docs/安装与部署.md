# 业码汇安装与部署

![业码汇](assets/yemahui-banner-small.png)

业码汇（FirmMatterCodeManagement）面向会计师事务所、税务师事务所及其他专业服务机构，提供项目分配、业务编号、签字人、开票、收款和权限管理。

## Windows 服务器部署

### 1. 下载并解压

从 [GitHub Releases](https://github.com/byttao/FirmMatterCodeManagement/releases) 下载最新的 `FirmMatterCodeManagement-win-x64.zip`，解压到固定目录，例如：

```text
C:\FirmMatterCodeManagement
```

请保留 ZIP 中的全部文件。`Manager.exe` 和 `BackendServer.exe` 分别依赖同级的 `Manager-internal` 和 `BackendServer-internal` 目录，不能单独移动 EXE。两个运行时目录已包含 Python 和所需依赖，启动时无需重复解压；正式运行无需安装 Python、Node.js 或 Rust。

从旧的单文件版首次切换到文件夹版时，旧版管理工具无法直接安装新格式 ZIP。请先在旧版管理工具中停止服务，关闭管理工具，备份整个 `data` 目录，再将新版 ZIP 解压覆盖原安装目录，保留原 `data`，然后运行新版 `Manager.exe` 启动服务。后续版本可在新版管理工具中正常升级。

### 2. 启动管理工具

双击 `Manager.exe` 并允许管理员权限。管理工具可以：

- 安装、启动、停止和卸载 Windows 服务；
- 设置监听地址、端口和外部访问地址；
- 配置 Windows 入站防火墙；
- 检查 GitHub 新版本；
- 选择本地 ZIP 执行离线升级；
- 在升级前备份数据库，失败时恢复程序和数据库。

### 3. 配置访问地址

| 设置 | 说明 |
| --- | --- |
| `127.0.0.1` | 只允许服务器本机访问 |
| `0.0.0.0` | 允许通过服务器本机、局域网 IP 或公网 IP 访问；发布包默认值 |
| 端口 | 默认 `8000`，管理工具会设置入站防火墙规则 |
| 外部 IP/域名 | 只填写地址，不要填写协议或端口 |

首次启用必须在服务器本机完成。管理工具会打开：

```text
http://127.0.0.1:端口/setup
```

域名需要提前配置 DNS。公网使用时，还应放行主机防火墙、云安全组或路由器端口转发。系统直接提供 HTTP，不包含 HTTPS；如需 HTTPS，再另行配置反向代理。

## 首次启用

1. 创建管理员账号，密码至少 8 位。
2. 选择首个编号年度并填写事务所名称。
3. 为每个事务所添加业务类型和编号模板。
4. 登录后在“用户管理”创建执业人员账号。
5. 在“签字人管理”中按执业账号关联签字人。同名人员通过账号区分。

编号模板支持：

| 占位符 | 含义 | 例子 |
| --- | --- | --- |
| `{yyyy}` | 四位编号年度 | `2026` |
| `{yy}` | 两位编号年度 | `26` |
| `{n}` 到 `{nnnnnnnnnn}` | 序号，按 `n` 的数量补零 | `{nnn}` → `001` |

模板必须包含 `{yyyy}` 或 `{yy}`，并且只能包含一个序号占位符。可以加入固定前缀、后缀或中文文字，例如：

```text
审计-{yyyy}-{nnn}       -> 审计-2026-001
{yy}/审-{nnnn}          -> 26/审-0001
```

编号年度是项目建立和发号所属年度，业务年度是审计对象所属年度。例如 2026 年办理 2024 年度和 2025 年度审计，应建立两份项目，编号为 `2026-001` 和 `2026-002`。

## 升级与数据继承

升级前不要覆盖 `data` 目录。该目录保存：

- `db.sqlite`：业务数据；
- `jwt_secret`：登录签名密钥；
- `server.json`：监听和端口配置；
- `updates`：升级记录和备份。

联网升级可以在管理工具中检查并安装新版本。离线升级时，从 Releases 下载 ZIP，在管理工具中选择本地 ZIP。工具会停止服务、备份数据库、替换程序并检查新服务；失败时会尝试回滚。

数据库迁移在服务启动时自动执行。迁移失败会阻止服务启动，并保留升级前备份。升级后请登录检查项目数量、编号历史、发票和收款流水。

## 开发模式

开发环境需要 Python 3.11+、Node.js 18+：

```bash
cd backend
python -m pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

另开终端：

```bash
cd frontend
npm install
npm run dev
```

访问 `http://localhost:5174`。生产单体模式需要先运行 `npm run build`，再把 `frontend/dist` 内容复制到 `backend/static`。

## 安全与备份

- 不要把 `data`、数据库、JWT 密钥或本地配置提交到 GitHub。
- 首次启用只应在服务器本机进行。
- 通过公网使用时配置 HTTPS，不要直接暴露 HTTP 登录页面。
- 定期备份整个 `data` 目录，并测试备份恢复流程。

Windows ZIP 内也包含一份可离线查看的 [`安装与初始化.html`](../windows/安装与初始化.html)。
## 商用授权接入

商用发布包可通过环境变量开启授权校验。授权服务器和授权管理工具位于独立项目“业码汇授权中心”，不随本仓库发布。

```text
FIRM_MANAGER_LICENSE_REQUIRED=1
FIRM_MANAGER_LICENSE_SERVER_URL=https://授权服务器域名
FIRM_MANAGER_LICENSE_PUBLIC_KEY=授权服务器 /api/public/signing-key 返回的 public_key
FIRM_MANAGER_LICENSE_FILE=数据目录/license.json
```

首次打开业码汇安装向导时，粘贴授权管理工具导出的 JSON 授权文件并完成激活。客户端只保存授权文件和公钥，不保存授权服务器私钥。授权服务器撤销、暂停、续期和实例解绑由内部授权管理工具完成。
