# v0.2.0 安装与部署

当前为总方案批次A的基础测试版本，完整步骤以[README](../README.md)和[Windows说明](../windows/安装与初始化.html)为准。

请保留原数据、密钥和配置，在新的固定本地目录安装。0.1.x数据库不会自动迁移，发现旧结构会拒绝启动，不能覆盖旧目录或自动清库。生产data不放NAS或同步目录。

默认直接HTTP监听0.0.0.0:8000。服务本机使用127.0.0.1；其他电脑使用可路由的内网或公网IP。Windows防火墙、安全组与端口转发须单独配置。公网IP填写到管理工具外部地址，形成Host白名单；程序不要求反向代理、域名或证书。

HTTP不加密密码、会话和业务资料，不能声称具有HTTPS的传输安全。首次初始化仅真实本机连接，密码至少12位。服务开机自启与异常重启，关闭管理工具不会停止服务。

后续实施与待验收项目见[实施状态](实施状态.md)。
