## 主项目覆盖范围

- 首次启用、管理员登录、权限角色和本机安装限制。
- 编号年度、事务所、业务类型、编号规则及 `{yyyy}`、`{yy}`、序号占位符校验。
- 2026 编号年度下建立 2024、2025 两个业务年度项目，验证编号依次使用 `2026-0001`、`2026-0002`，不按业务年度编号。
- 项目分配、执业人员签字人绑定、重名人员账号区分及签字项目查询。
- 发票和收款逐笔登记、汇总、余额和导出。
- 编号发放、回收、历史追踪及格式冲突保护。
- 数据库迁移、旧版汇总数据迁移、签字人历史数据保留。
- Windows 管理工具核心逻辑：服务健康检查、配置地址、安装包校验、数据库备份、升级回滚和路径安全。
- 升级过程拒绝降级、拒绝错误版本包，升级失败恢复程序和数据库。
- 客户端授权状态：有效、暂停、撤销授权文件均按预期处理；未启用授权时保持开发模式兼容。
- 授权服务器心跳明确拒绝后，本地业务 API 被阻止；临时断网不写入阻止标记，重新激活后清除阻止标记。

## 授权中心覆盖范围

- 管理员登录、客户创建、授权签发和 Ed25519 签名校验。
- 实例数量上限、用户数量上限、版本范围和离线宽限期。
- 授权续期、暂停、恢复、撤销和实例解绑。
- 心跳上报、审计记录及签名篡改拒绝。

## 构建验证

- `python -m unittest discover -s backend/tests -p 'test_*.py' -v`：24/24 通过。
- `python -m unittest discover -s license-server/tests -p 'test_*.py' -v`：8/8 通过。
- 前端 TypeScript 检查与 Vite 生产构建：通过，生成 `frontend/dist`。

授权中心统一使用 `/api/v1/activate` 与 `/api/v1/heartbeat` 版本化客户端接口，覆盖产品编码校验、按实例 ID 精确心跳、续期后同步新签名许可证和结构化错误码。授权客户端还会拒绝与安装包内置公钥不匹配的激活响应。续期不会自动解除暂停状态；换机仍需管理员先解绑旧实例。

Windows EXE 和 Windows 服务需要在 Windows Server 或 Windows 环境进行最终安装和启动烟测。本次改为 PyInstaller `--onedir` 后，管理工具升级测试覆盖运行时目录替换和失败回滚。当前 macOS 环境无法执行 PowerShell、PyInstaller Windows 构建或 Windows 服务烟测；GitHub Windows Runner 可在发布流程中完成验证。正式 Windows 发布需配置与授权服务器签名私钥匹配的 `FIRM_MANAGER_LICENSE_PUBLIC_KEY`。
