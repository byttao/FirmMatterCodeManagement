# v0.1.21 完善授权试用、客户管理和登录能力

## 主要修改

- 增加试用授权和授权状态管理，试用限制为 1 个编号年度、3 名执业人员、3 个项目。
- 增加事务所简称、LOGO、页面标题和 banner 展示设置。
- 增加客户主数据管理和税号关联，保留客户名称变更记录，便于通过统一税号查找历史项目。
- 支持手机号与用户名登录，数据库迁移增加手机号、客户及短信验证码挑战记录。
- 预留短信验证码请求与登录接口。
- 项目列表支持配置显示列和多级排序。
- Windows 管理工具显示授权状态；Mac 和 Windows 部署包均支持随包配置监听地址，服务默认监听所有网络接口。
- 更新安装说明与数据库迁移至版本 6。

## 验证

- Python 后端和 Windows 管理工具编译通过。
- 后端完整测试套件通过。
- 前端 Vite 生产构建通过。
