# v0.1.22 修复初始化向导布局并支持 .liscence 授权文件

## 主要修改

- 修复多个事务所、多个业务类型和不同编号模板同时配置时的控件错位；长模板也不会挤压相邻控件。
- 优化移动端初始化向导布局，删除业务类型按钮在窄屏下保持右对齐。
- 初始化向导授权文件选择改为 `.liscence` 后缀，文件内容仍按 JSON 文本解析。
- 选择有效授权文件后，自动读取其中的 `server_url` 填充授权服务器地址。

## 验证

- 初始化向导通过 ego-browser 在桌面和 390px 移动视口完成多事务所、多业务类型、多模板交互验证。
- 后端完整测试套件 24 项通过。
- 前端 Vite 生产构建通过。
