# v0.7.4 统一登录密码为至少8位且包含字母和数字

两个程序的登录密码规则统一为8至72位，必须同时包含英文字母和数字；不要求特殊符号，UTF-8编码仍不超过72字节。覆盖初始化、账号创建、管理员重置和本人改密的适用入口，前后端与安装提示同步。业务所有角色使用相同规则，授权中心保持唯一管理员。

保留现有密码哈希与登录验证，不强制修改旧密码；未清理现有数据、替换密钥或改变库结构（业务700/中心400，协议2）。加密备份口令保留独立的12至128位规则。Windows冻结包自检使用随机8位字母数字登录密码及独立备份口令。

测试：本机77项全部通过（47.003秒）；TypeScript/Vite构建通过。新增8位初始化、创建/改密/重置、纯字母/纯数字拒绝、UTF-8上限及旧密码登录回归；网页规则函数和HTML pattern边界通过。Windows精确Tag CI和正式包下载校验在推送后记录，目标Windows2019手工所有角色操作仍待验证。

Windows回归补丁：v0.7.3因新增初始化测试误用开发机绝对导入路径而失败，未发布正式Release。保留失败Tag；本版本依据测试文件位置构造运行仓库路径，并从无关临时工作目录启动子进程，验证Windows/Mac路径可移植性。密码功能实现与既有结构保持。补丁本机验证在独立临时cwd执行初始化测试通过，重新网页构建通过；本版完整Windows回归、冻结构建和下载结果在独立报告补充。
