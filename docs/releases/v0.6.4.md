# v0.6.4 中文错误与管理员运行诊断

新增仅事务所管理员可用的运行日志查询及脱敏诊断导出，支持按请求编号、用户ID、时间和级别定位执业人员的问题。普通角色直接访问接口也会被拒绝；授权只读或恢复保护期间仍可由管理员排查。

统一中文错误类别、原因、错误代码和请求编号；覆盖接口校验、网络故障、JSON/文件错误、原生表单提示及二进制下载错误。5xx不返回内部异常原文，日志仅记录脱敏异常类型和代码位置。导出任务补齐完整任务编号、请求编号及生成结果关联。

诊断读取最新记录，默认24小时、最大31天，单次扫描12MiB/5000条，导出正文5MiB；诊断单并发下载限速100KiB/s。截断状态明确标注，日志写入失败不改变已提交业务的响应。

本机59项回归通过、TypeScript/Vite构建通过，浏览器验证普通人员拒绝访问、管理员查到对应403记录并按条件下载成功。Windows冻结EXE及LocalService由发布流水线验证；实际Windows Server 2019低配、外部网络和2Mbps混合负载仍需实机验收。

仅本机旧测试数据按用户要求清空，编号系统回到首次安装；发布包不会执行自动清库。包内不含测试数据、密钥或运行日志。
