# v0.1.20 授权联动与 Windows 文件夹部署

## 主要修改

- 对接鷐鉴授权中心的版本化激活与心跳接口。首次启用可导入 JSON 授权文件；续期后的签名许可证可通过心跳同步。按已启用执业人员统计授权人数，并在后端校验功能模块权限。
- 授权中心明确拒绝实例时阻止业务 API；短时断网仍按本地许可证和宽限期处理。
- SQLite 文件库启用 WAL、写入等待时间和连接配置，改善多人同时访问时的表现。
- Windows 发布包改为 PyInstaller `--onedir`。管理工具升级时整体替换运行时目录，并在失败时恢复程序和数据库；启动无需反复解压 Python 运行时。
- 补充跨年度、授权和 Windows 升级测试，更新安装说明与数据测试报告。

## 验证与部署说明

- 业码汇后端测试 24/24、鷐鉴授权中心测试 8/8 通过；前端 TypeScript 检查与 Vite 构建通过。
- 首次从旧单文件版切换到本版时，先停止服务、备份并保留 `data` 目录，再将新版 ZIP 解压覆盖原安装目录。旧版管理工具不能直接安装文件夹模式 ZIP。
- Windows 发布包由 GitHub Actions 构建并附加到本 Release。实际 Windows Server 环境的安装、升级与性能验收仍需完成。
- 商用安装包内置与现有鷐鉴服务器对应的授权公钥。迁移鷐鉴服务器时必须安全保留其签名私钥和运行数据，否则既有授权文件将无法继续验证。
