# v0.1.24 优化授权状态与授权导入界面

## 主要修改

- 授权状态增加签约公司、执业人员授权额度与现有人数、项目授权额度与已有项目数、授权服务器连接状态和地址。
- 授权服务器地址改为必填；选择 `.liscence` 文件后自动读取 JSON 内容和文件内的 `server_url`。
- 左侧管理员菜单调整为：数据看板、客户管理、项目管理、用户管理、签字人管理、编号年度配置、授权与品牌。

- 前端 TypeScript 检查与 Vite 生产构建通过。
- ego-browser 验证授权状态展示、菜单顺序、`.liscence` 文件读取，以及服务器地址为空时禁止提交。
